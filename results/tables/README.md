# Result Tables

This directory contains processed experiment summaries generated from raw measurements.

The purpose of these tables is to provide structured views of experimental results for performance analysis.

## Data Source

Raw experimental data is stored under:

```
experiments/raw/
```

The tables in this directory are generated from the corresponding raw measurements.

## Contents

Typical results include:

- Proof generation summaries
- Verification performance summaries
- Prover stage breakdowns
- Profiling analysis results

## Reproducibility

Each table should be traceable to:

- Original raw data
- Experimental environment
- Execution configuration
- Source version

Raw measurements should not be replaced by processed results.
