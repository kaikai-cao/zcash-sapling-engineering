# Zcash Sapling 工程研究 —— 结项摘要（2026-10-30）

**范围**：2026-10-11 至 2026-10-30，Zcash Sapling zk-SNARK 证明性能的工程测量、瓶颈定位、
优化验证与交易级成本测量。
**仓库**：`kaikai-cao/zcash-sapling-engineering`；主要成果位于分支
`experiments/e2e-testnet-tx-harness`（PR #24，**open，未合并**）。
**状态**：**已冻结**。不再新增实验、指标或脚本。
**入口**：交易级部分见 `experiments/e2e_testnet_tx/FREEZE.md`；证明器部分见 `README.md` §7 与
`docs/sapling_proving_optimization_final_report_zh.md`。

> 本文给读者（导师/评审）一份十分钟可读完的全线视图：研究了什么、发现了什么、真正优化了什么、
> 哪些方向失败了、结论的边界在哪里。**不替代**各阶段的原始报告，只做收敛与指路。

## 0. 一页速览

**研究问题**：在真实可复现的工程条件下，Zcash Sapling 的 Groth16 证明成本由什么构成？
在不动电路、不动协议的前提下，能改的到底是哪一层、能改多少？把"单次证明"扩展到"整笔交易"后，
成本结构是否还成立？

**六阶段路线与结论**：

| 阶段 | 内容 | 结论 |
|---|---|---|
| 一 | 建立真实基线 | Spend 3,385.716 ms / Output 514.853 ms（单线程中位），参数与电路规模全部核验 |
| 二 | 定位瓶颈 | 证明耗时 ≈85% 在 MSM，MSM ≈78% 在 bucket fill，单位成本 ≈462 ns/非零数字 |
| 三 | 优化验证（预注册） | 内存 **103.06 → 86.18 MB（−16.38%）** 已作为出厂默认；六个方向以负结果关闭 |
| 四 | 交易构造实验 | 真实 Builder 全流程 4,292.7 ms（1 线程）/ 1,176.1 ms（8 线程），**99.89% 是证明** |
| 五 | 确认性交易成本实验 | 50 轮 / 10 形态 / 0 失败；`T = 641.5·S + 101.0·O + 650.5 ms`，R²=0.9996；三项预注册假设全部接受 |
| 六 | 冻结 | 数据、代码版本、偏离、证据分级、复现路径与不可越界表述全部落档 |

**四句话总结**：证明器层面拿到的是一次**经过预注册认证的内存优化**（−16.38%）和一批**有据可依的
负结果**；交易层面拿到的是一个**精确到毫秒级的成本模型**（R²=0.9996）；两者都**只在本实现、
本环境内成立**；研究线在此收口，下一步转 Halo2 与论文选题。

## 1. 阶段一：真实基线（不是"跑个 benchmark"）

全部数字来自 release 构建、绑定线程、参数文件哈希核验后的正式批次，而非快速试跑。

| 指标 | Sapling Spend | Sapling Output |
|---|---:|---:|
| Prove 中位 | **3,385.716 ms** | **514.853 ms** |
| Verify 中位 | 2.790 ms | 2.150 ms |
| 序列化证明大小 | 192 B | 192 B |
| 电路约束数 | 98,777 | 7,827 |
| 辅助变量 | 98,638 | 7,821 |
| FFT 域大小 | 131,072 | 8,192 |
| 参数文件 | 45.737 MiB | 3.426 MiB |

这一阶段的方法论价值在于把三组容易混淆的量分开：

1. **参数文件大小 ≠ 概念上的 CRS/PK/VK**——文件里装的是同一套结构的多个多项式承诺；
2. **约束数 ≠ 辅助变量数 ≠ FFT 域大小**——域大小是约束数向上取整到 2 的幂，直接决定 FFT 成本；
3. **Prover 耗时 ≠ Verifier 耗时**——相差三个数量级，任何"SNARK 很慢"的说法都必须指明是哪一侧。

## 2. 阶段二：瓶颈定位（从毫秒深入到纳秒）

这是整条线里工程分析密度最高的部分，逐层下钻：

| 层级 | 结论 | 手段 |
|---|---|---|
| 证明函数 | MSM ≈ **85%** of prove | 阶段拆解 + 源码级插桩 |
| MSM 内部 | bucket fill ≈ **78%** of MSM | 调用级计时，按 query 分组 |
| 桶内算术 | **≈462 ns / 非零数字**（≈470 ns 混合加） | 单位成本探针，与实际耗时对照 |
| 窗口参数 | c = 13 对三个大 query 均最优 | 操作数模型，非试错 |
| 线程扩展 | 8 线程 ≈5×，拐点由 H-query 窗口尾部解释 | 绑核 + ABBA 交叉 |
| 跨实现对照 | bellman = **1.9063× blst**（CI95 [1.8999, 1.9110]） | 同输入、同线程数的独立基准 |

**最关键的一条口径修正**：462 ns 不是 Pippenger 算法的下界，而是**本仓库 vendored bellman 的实现级
单位成本**——同一主机、同等操作数下，blst 只需约 253 ns/操作（约一半）。这条修正的意义是：
它把"优化到地板了"这一说法从**算法断言**降级为**实现断言**，从而没有把"我这个实现没得改了"
误写成"这个问题没得改了"。

## 3. 阶段三：优化验证（预注册 + 负结果）

所有优化都在**先冻结验收指标、再跑实验**的规则下进行，避免"跑完再挑指标"。

| 目标 | 内容 | 结果 |
|---|---|---|
| **b** | 有符号窗口重编码（MSM bucket fill） | **认证**，成为出厂默认 |
| **a** | 惰性重编码（去物化窗口指数） | 未达冻结阈值（12.93 MB < 15 MB），**归档，默认不变** |
| **f** | 单线程 FFT 四步 scratch 消除 | **通过**，成为组合的一部分 |
| **g** | 组合（b 类 + f） | **通过**，两个开关翻为默认 `1` |
| Stage 1b | 自适应窗口 / 尾窗切分 | `C1/C0=1.019`，未降；**负结果，默认不变** |
| Stage 2 | c=12 实测点 | 违反 no-reversal 守卫，**NO_GO** |
| Stage 3 | 两个 Spend 共享线程池 | 点估计 −16.38% 但一组反向，**NO_GO** |
| Stage 4 | QAP/FFT 流水线切分 | QAP −18.84% 但 body 仅 −3.89%（<5%），**未开正式阶段** |
| Stage 5 | FFT 算术（radix-4 等） | 单线程 1.553×，生产 8 线程仅 1.246×（<1.25 门槛），**MARGINAL** |
| Stage 6 | 电路综合侧削减 | 理论上限仅 4.63% of body（<5%），**NO_GO** |

**唯一进入出厂默认的正式收益**：

```
Spend prove 峰值：103.06 MB → 86.18 MB（−16.38%，−16.88 MB）
验收指标：prove_peak_abs_bytes（非整进程 PeakWorkingSet 的前后对照）
正确性：全部位级一致 + 证明验证 100% 通过，时间无回退
```

保留负结果的理由：**"这个方向不值得继续"本身是可复用的结论**。六个方向以 NO_GO/MARGINAL 关闭，
为后来者省掉的是重复投入，而不是"没做出来"。

## 4. 阶段四：交易构造实验（从函数到整笔交易）

单测 `create_proof` 得到的 3,385.716 ms 无法回答"发一笔交易要多久"。本阶段把真实
`Builder::build(...)` 跑通：

- 固定场景：1 spend + 2 outputs，ZIP-317 手续费，合成 32 层 Merkle 路径，与基线同一套参数文件；
- 结果：**4,292.7 ms（单线程）/ 1,176.1 ms（8 线程）**，含序列化，暖机中位；
- 结构：**99.89% 的时间是 Groth16 证明**，序列化与其它构造开销可忽略。

这条结果直接决定了后续研究不需要再在"构造逻辑"上投入——瓶颈完全在证明。

随后扩展到**端到端钱包流程**（2026-10-29 试点）：`z_sendmany` 路径、每轮从同一快照恢复、
链高一致，29 轮 / 11 个 (spends, outputs) 形态，得到 `T ≈ 589.9·S + 91.5·O + 424.2 ms`，
R²=0.9998，Spend/Output ≈ **6.45:1**（试点估计），ZIP-317 手续费 29/29 匹配。
PCZT 四阶段路径被工具链阻断（`sapling_signed=0`、`MissingProofGenerationKey`，24 轮全部失败），
作为**工具限制证据**保留，不计入成本模型。

## 5. 阶段五：确认性交易成本实验（预注册，50 轮）

试点只是可行性证据。正式结论来自**预注册 + 门禁 + 正式采集**三段式：

| 项 | 值 |
|---|---|
| 预注册 | `experiments/metadata/sapling_e2e_regtest_confirmatory_preregistration_20261030.md`（冻结；执行后状态见 §14） |
| 样本 | **50 轮 = 10 形态 × 5**，每轮前从同一快照恢复 |
| 质量 | 失败 0 / 重试 0 / 形态不匹配 0 / 手续费不匹配 0 / txid 50/50 |
| 环境一致性 | 链高 **32297**、可花费 note **36**、余额 11999980000 zat，50/50 全一致 |

**成本模型**（M3，预注册指定形式）：

```
T = 641.5·S + 101.0·O + 650.5  ms      R² = 0.9996,  LOO-RMSE = 83.3 ms
Spend/Output 单位成本比 ≈ 6.35 : 1
```

**三项预注册假设全部接受**：

| 假设 | 判据 | 实测 |
|---|---|---|
| H_A：Spend 单位成本 > Output | Δ 的 95% CI 下界 > 0 | Δ=540.57 ms，CI [513.11, 552.96] |
| H_B：等证明数形态间有稳定差异 | 中位数差 CI 不含 0、同号、量级 ∈[300,800] ms | 632.90 ms，CI [483.10, 783.20] |
| H_C：双变量模型优于单变量 | LOO 降幅 ≥10% 且 M3 < M2 | 1490.12 → 83.31 ms（−94.4%），83.31 < 275.04 |

**被否证的常见简化**：按证明个数计价（M1，即 `a·(S+O)+b`）的 LOO 误差是 M3 的 **17.9 倍**——
说明"一个 proof 一个价"在本流程里是错的，output 与 spend 的边际成本差约 6.35 倍。

**必须与结论同时出现的三条限制**（详见 `RESULTS.md` §6）：

1. 环境是 **WSL2 离线 Regtest + Zallet Beta**，不是 Testnet；相对成本比的**可迁移性尚未验证**，
   不得外推至主网、其它钱包版本或其它硬件。
2. 样本顺序实为**形态块随机化**（非预注册要求的逐次随机）。探索性诊断显示，加入顺序项后
   Δ 由 540.20 → 528.36 ms（−2.2%，仍远大于 0），而 output 边际由 101.52 → 111.48 ms（**+9.8%**）。
   故 **101.0 ms 应作区间量引用**，H_A/H_B/H_C 判定不受影响。
3. 每形态 n=5，形态级 bootstrap 区间较宽（output 系数形态级 CI [32.1, 336.9]）。

## 7. 什么被证实 / 什么被否证 / 什么没做

**被证实**（有预注册判据或强证据支撑）：

- 证明耗时结构：MSM ≈85% → bucket fill ≈78% → 462 ns/数字（本实现）；
- 内存优化可认证且可交付：−16.38%，正确性 100%，作为出厂默认；
- 交易成本可用 `a·S + c·O + b` 精确刻画，且 S 与 O 的边际成本显著不等；
- 按证明个数计价在本流程中不成立。

**被否证 / 关闭**（负面但有效）：

- 自适应窗口、c=12 实测点、证明并发共享线程池、QAP/FFT 流水线、FFT 算术、电路综合削减——
  六个方向均未过各自冻结门槛，**默认值一个都没动**。

**明确没做**：

- Testnet / 主网实验（同步成本 2–12 小时 + faucet，且不改变结论方向）；
- MSM 内核 Phase D（xyzz 桶 fill 内核）——仅文档化，未实现，需另立预注册；
- 逐轮墙钟时间戳、逐轮进程级二进制采样——数据侧未记录，补采须重跑；
- 钱包端完整内存结论——采样未覆盖 `zallet-zaino`；
- 交付物 4（汇报 PPT 修订）——独立事项，不影响材料冻结。

## 8. 边界（引用本研究时必须一并说明）

1. **环境**：WSL2 离线 Regtest，单机单会话；不是 Testnet，不含网络传播与 mempool 竞争。
2. **可迁移性**：**未验证**。相对成本比具有一定的跨网络参考价值，但在不同钱包版本、硬件、
   部署环境下是否成立，需独立实验。
3. **口径**：641.5 ms/spend 是**钱包交易流水线**（build + prove + sign + broadcast，不含出块确认）
   中一个 spend 的**边际成本**，**不是** Groth16 Spend 证明时间（3,385.716 ms），也**不是**
   任何"算法加速"。
4. **证据等级**：二进制哈希末轮为进程级实测，其余为同文件推定；不得合并表述为"全程逐轮实测"。
5. **样本量**：每形态 n=5，按冻结方案执行，不追加。
6. **工程 ≠ 算法**：本文所有收益均属本实现层面的工程优化；线程扩展带来的加速不是算法改进。
